Pintura

    Enter to save, Esc to cancel

    Keyboard shortcuts

    Navigate

    ← → Space
    Previous or next slide, or layout while editing one
    Home End
    First or last slide, or layout while editing one
    Mouse wheel
    Previous or next slide or layout over the slide or in present mode, or scroll a zoomed slide
    S G T
    One slide, every slide, or the theme
    \
    Show or hide the slides
    |
    Show the slides beside or below the slide
    P F5
    Present
    Esc
    Clear the selection, or stop presenting

    View

    I
    Show or hide the inspector
    O
    Show areas and placeholders
    Ctrl + wheel, pinch
    Zoom the slide or grid about the pointer
    Ctrl + + - 0
    Zoom the slide or grid in, out, or back to fit
    Ctrl + click
    Open a linked number in Libreta

    Edit

    Tab Shift + Tab
    Select the next or previous element
    Drag across the slide
    Select the elements the box touches
    Shift or Ctrl + click
    Add an element to the selection, or take it out
    Double-click
    Reword text in place
    Ctrl + B I U
    Bold, italic, or underline the selected words while rewording
    Shift + Arrow
    Nudge the selected elements 10 pt
    Delete
    Remove the selected elements, or the slide focused in the sidebar or grid
    Ctrl + Z
    Undo the last mouse edit

    Comments

    Right-click
    Comment on the slide, or the element under the pointer
    M
    Show or hide comments
    N Shift + N
    Next or previous slide with comments

    Changes

    Ctrl + S
    Save the changes as a new version
    D
    Show only the changed slides, or every slide
    B
    Flip to the version compared against
    C
    Mark the changes since it
